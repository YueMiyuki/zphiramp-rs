Option                               Description                               
------                               -----------                               
--empty-room-ttl <Integer>           Minutes a room may stay empty before being
                                       reclaimed (0 disables reclaiming)       
                                       (default: 60)                           
--help                               Show this help message                    
--host <String>                      Bind address (IP to listen on) (default:  
                                       0.0.0.0)                                
--http-host <String>                 HTTP API bind address (default: 0.0.0.0)  
--http-port <Integer>                HTTP API listening port (default: 8080)   
--language <String>                  Default server language (e.g., zh-CN, en- 
                                       US) (default: zh-CN)                    
--login-rate-limit <Integer>         HTTP login attempts allowed per minute per
                                       client address (-1 for no limit)        
                                       (default: 30)                           
--max-connections <Integer>          Maximum simultaneous connections (default:
                                       1000)                                   
--max-pending-submissions <Integer>  Pending chart submissions allowed per     
                                       account (-1 for no limit) (default: 50) 
--max-rooms <Integer>                Maximum rooms alive at once (default: 200)
--plugins <String>                   Plugins directory path (default: plugins) 
--port <Integer>                     Server listening port (default: 12346)    
--proxy-protocol [Boolean]           Enable proxy protocol support (default:   
                                       false)                                  
--read-timeout <Integer>             Seconds before an idle client is dropped  
                                       (default: 3600)
